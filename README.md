# Smart Phantom Control

Server-side-only Fabric mod (no client mod needed - works in Singleplayer,
since SP is a local server, and on any Fabric server). Replaces vanilla's
Phantom insomnia spawner with a tunable version: custom eligibility
threshold, per-eligible-night spawn-chance caps and group-size caps, falling
back to plain, uncapped vanilla behavior once the configured tiers run out.

Current build: **A0.1** (first release), **MC 26.2 only**.

## Install

Server-side only, needs Fabric Loader + **Fabric API**. No client-side
component and no client mod required for players joining a server that has
this installed.

## Default preset

Eligibility threshold unchanged from vanilla (night 3). From there:

| Night           | Chance cap | Max group size |
|-----------------|-----------|-----------------|
| 1st eligible    | 10%       | 1               |
| 2nd eligible    | 30%       | 2               |
| 3rd eligible    | 40%       | 2               |
| 4th eligible    | 50%       | 3               |
| 5th eligible on | vanilla (uncapped) | vanilla (1-4, difficulty-based) |

Config is global by default (one file, applies to every world/server), but
can be switched to per-world (`"configScope": "per_world"`) so each world
gets its own independently-tuned copy. Full config documentation (all
fields, worked examples, troubleshooting) lives in
`Readme_phantomcontrol.md`, shipped alongside the jar.

## Building from source

```
cd 26.2
./gradlew build
```

Built jar lands in `26.2/build/libs/`. Needs JDK 25.
